淘宝 / 天猫 / Facebook 视频助手 · 无需第三方 API

通过 Netlify Functions 在服务器端读取公开页面，并尝试提取页面中公开暴露的视频地址。无需支付宝、AppKey 或第三方解析 API。需要登录、验证码、私密权限、付费或受 DRM 保护的视频不会被绕过；因此不能保证每个链接都成功。

手机 / 电脑辅助提取（无需第三方 API）

先在淘宝/天猫或 Facebook 页面打开视频，尽量点播放，再运行下面的书签脚本。它只检查当前浏览器页面已加载的元素和资源，不会登录或绕过平台限制。

  1. 把下方脚本复制。
  2. 在浏览器新建一个书签，将书签网址/URL 替换为复制的脚本。
  3. 打开商品页，点这个书签；如果找到候选视频，复制地址回到本网站粘贴。

iPhone Safari：先随便添加一个书签，再编辑书签，把网址替换成脚本。Android / 电脑：也可创建书签并把网址设为脚本。不同浏览器可能限制书签脚本运行。仅处理你有权访问和保存的内容。
